Features

Everything a real PDF throws at you

Most converters work on a clean demo and fall apart on the document you actually have. pdf2json was built against a 48-page government table — the messy real thing.

Borders or whitespace

Reads column boundaries from the table's drawn cell borders when present — even cells drawn as filled rectangles — and falls back to whitespace detection when there's no grid.

Headers that carry forward

A 48-page table whose header only prints on page 1 stays fully labelled. Many small tables that share one column layout keep a single consistent set of labels.

Section titles, not phantom rows

Red or bold titles become their own heading field instead of being folded into a row — and that's exactly what keeps a wrapped multi-line cell whole.

Untangles overlapping text

Reads words in the PDF's character-stream order, so interleaved headers like the garbled COIDNESTITUTION come back as clean CODE + INSTITUTION.

Splits glued values

A row number fused to the next column (11105101) or a value stuck to its neighbour (40.571MAT) is detected from the data and split back at the boundary.

Optional spell correction

A dictionary pass fixes genuine typos (Univrsity → University) while leaving codes, numbers, and all-caps proper nouns untouched. Toggle it off anytime.

FAQ

          
Questions, answered

        

        

          

            Is pdf2json free? 
            
Yes — completely free and open-source under the MIT license. Use it on the command line or in the browser at no cost, in personal or commercial projects.

          

          

            Do my PDFs get uploaded anywhere? 
            
The command-line tool runs entirely on your machine — nothing is sent anywhere. This hosted web app processes the file on its own server only to produce the JSON, then discards it immediately; it is never stored or shared. For maximum privacy, run the CLI locally.

          

          

            What kinds of PDF tables work best? 
            
Both ruled tables with drawn borders and whitespace-separated columns. pdf2json carries headers across pages, untangles overlapping text, stitches multi-line cells back together, and splits glued values. It works on text-based PDFs — scanned image-only PDFs would need OCR first.

          

          

            What does the output look like? 
            
A JSON object with source, section_count, total_rows, and a sections list. Each section has a heading, a page number, and a rows list, where every row maps each column label to its cell value.

          

          

            Can I use it in scripts or a data pipeline? 
            
Absolutely. Install with pip install pdf2json and run pdf2json input.pdf to get input.json. It supports batch mode over folders and slots cleanly into ETL pipelines.

          

          

            How accurate is it? 
            
pdf2json prefers a table's real drawn borders over alignment guesswork, which makes column detection far more reliable than naive whitespace splitting. It's tested against a real 48-page document with a byte-for-byte expected-output fixture.
